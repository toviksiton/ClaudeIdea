# 🍽️ מטבח הכפר — מערכת הזמנות אוכל ביתי

מערכת להזמנת אוכל לאירועים מקומיים עם ניהול מלאי, תפריט דינמי, מסך מטבח ותשלום דיגיטלי.

---

## 🚀 התקנה והפעלה (Mac)

### שלב 1 — התקנת Node.js (פעם אחת בלבד)

1. פתח את הדפדפן ועבור ל: **https://nodejs.org**
2. לחץ על הכפתור הירוק **"Download Node.js (LTS)"**
3. פתח את הקובץ שהורד והתקן אותו
4. פתח Terminal חדש וודא שההתקנה הצליחה:
   ```
   node --version
   ```
   אמור להופיע משהו כמו: `v20.x.x`

---

### שלב 2 — הורדת הפרויקט

פתח Terminal והרץ:

```bash
git clone https://github.com/toviksiton/claudeidea.git
cd claudeidea
git checkout claude/local-food-marketplace-4LaT9
```

> אם אין לך `git`, הורד מ: https://git-scm.com/download/mac

---

### שלב 3 — הגדרה ראשונה (פעם אחת בלבד)

```bash
chmod +x scripts/setup-mac.sh
./scripts/setup-mac.sh
```

הסקריפט יתקין את כל מה שצריך ויכין את מסד הנתונים אוטומטית.

---

### שלב 4 — הפעלה יומיומית

```bash
./scripts/start.sh
```

הסקריפט יציג את כתובות הגישה לרשת.

---

## 🔗 כתובות הגישה

לאחר ההפעלה, כל המכשירים ב-WiFi אותו יכולים לגשת:

| מסך | כתובת | מי משתמש |
|-----|--------|-----------|
| 🛒 הזמנות לקוח | `http://[IP]:3000` | הלקוחות (שתף את הקישור) |
| 👨‍🍳 מסך מטבח | `http://[IP]:3000/kitchen` | הטבח / בעל המטבח |
| ⚙️ ניהול | `http://[IP]:3000/admin` | בעל העסק בלבד |

> `[IP]` = כתובת ה-IP של ה-Mac שלך (הסקריפט מציג אותה אוטומטית)
>
> **חשוב:** כל המכשירים חייבים להיות מחוברים לאותה רשת WiFi!

---

## 📱 שיתוף עם לקוחות

כאשר האפליקציה רצה, שלח ללקוחות את הכתובת שמציג הסקריפט, לדוגמה:
```
http://192.168.1.50:3000
```
הם יוכלו לפתוח מהטלפון ולהזמין.

## ⚙️ הגדרות ראשוניות (חשוב!)

אחרי ההתקנה, היכנס לפאנל הניהול ועדכן:

1. **כניסה:** `http://[IP]:3000/admin` | סיסמה: `admin123`
2. **הגדרות ← שנה:**
   - שם העסק שלך
   - מספר הטלפון
   - קישור Paybox שלך
   - מספר Bit שלך
   - **שנה את סיסמת המנהל!**
3. **מלאי:** עדכן את הכמויות לפי מה שיש לך
4. **תפריט:** הוסף/ערוך פריטים לפי הצורך

---

## 🎛️ תכונות המערכת

### ניהול מלאי חכם
- כל פריט תפריט מקושר למרכיבים (לחמניה, קציצה, רוטב...)
- כשמרכיב אוזל → הפריט יוצא אוטומטית מהתפריט עם תגית "אזל המלאי"
- מעקב כמויות עם התראות על מלאי נמוך

### מסך מטבח
- 4 עמודות: ממתין → אושר → בהכנה → מוכן
- מתעדכן כל 8 שניות אוטומטית
- צליל ופלאש ירוק על הזמנה חדשה (כולל הזמנות טלפוניות שהוזנו ידנית)
- התראות מלאי בחלק העליון

### תשלום
- **Paybox:** קישור ישיר לתשלום
- **Bit:** מציג את המספר לשליחת כסף
- **מזומן:** ניהול ידני

## ❓ בעיות נפוצות

**"npm: command not found"** → Node.js לא מותקן. חזור לשלב 1.

**"cannot find module"** → הרץ מחדש: `npm install`

**הלקוחות לא מצליחים להתחבר** → ודא שכולם באותה רשת WiFi ושהאפליקציה רצה.

**שכחתי סיסמת מנהל** → ערוך בהגדרות או מחק `prisma/dev.db` והרץ שוב `setup-mac.sh`.
